# Clean Architecture, .NET Aspire (.NET 10) & React 19 Enterprise Stack

A full-stack, cloud-native enterprise reference application built with **.NET 10 (C# 13)**, **.NET Aspire**, **Clean Architecture**, and **React 19** + **Tailwind CSS v4** + **shadcn/ui** + **TanStack Query v5** + **Axios**.

---

## 🌟 Key Architecture & Features

### 💻 Frontend Tech Stack (`client/`)

- ⚛️ **React 19**: Modern UI actions, hooks, and compiler optimization.
- 🎨 **Tailwind CSS v4**: High-performance zero-config CSS engine with `@tailwindcss/vite`.
- 🧩 **shadcn/ui Design System**: Reusable, accessible UI components built with Radix primitives and `class-variance-authority` (cva).
- 🔄 **TanStack Query v5**: Declarative caching (`useQuery`), mutation lifecycle (`useMutation`), and automatic cache invalidation (`queryClient.invalidateQueries`).
- 🛡️ **Axios with Interceptors**: Automatic Bearer token attachment, Correlation ID injection (`X-Correlation-ID`), and **Automatic 401 Refresh Token Rotation**.
- 📊 **Excel Integration**: In-browser export and multipart streaming import of `.xlsx` files generated by EPPlus.

### 🏛️ Backend Tech Stack (`src/`)

- 🚀 **.NET Aspire Cloud-Native Orchestration**: `CleanArch.AppHost` & `CleanArch.ServiceDefaults` with OpenTelemetry, Health Checks (`/health`, `/alive`), and Aspire Dashboard.
- 🏛️ **Clean Architecture (4 Layers)**: Domain (pure C#), Application (CQRS with MediatR & FluentValidation), Infrastructure (EF Core 10 SQLite, EPPlus 8, Identity), WebApi (Controllers, ProblemDetails, Scalar OpenAPI).
- 🔐 **Identity & Security**: PBKDF2 HMAC-SHA512 password hashing, JWT Bearer tokens, dynamic policies with `IAuthorizationPolicyProvider`, and `[HasPermission("...")]`.
- ⚡ **API Idempotency Pattern**: Stripe-standard `Idempotency-Key` header validation, atomic in-flight locking, and replay caching.
- 💾 **Caching & Distributed Locks**: In-Memory Cache (`IMemoryCache`), HTTP Output Cache (`[OutputCache]`), and Distributed Locking with Redis.
- 🧪 **Automated Testing & CI/CD**: 42 xUnit tests (Moq, FluentAssertions, EF Core InMemory) and automated GitHub Actions CI/CD workflows.

## 🚀 Quick Start Guide

### 1. Run the Backend (.NET 10)

```powershell
# Option A: Run with .NET Aspire Orchestration & Dashboard
dotnet run --project src/CleanArch.AppHost

# Option B: Run Web API directly
dotnet run --project src/CleanArch.WebApi
```

Backend API runs at `http://localhost:5000` with Scalar UI at `http://localhost:5000/scalar/v1`.

### 2. Run the Frontend (React 19)

```powershell
cd client
npm install
npm run dev
```

Frontend runs at `http://localhost:3000` (automatically proxies API requests to `http://localhost:5000`).

### 3. Run Automated Unit & Integration Tests

```powershell
dotnet test IdentityCleanArch.slnx
```

Runs all 42 xUnit tests across Domain, Application, CQRS commands, and Infrastructure services.

### 4. Run Multi-Container Docker Stack

```powershell
docker compose up --build
```

Runs both the .NET 10 API (`:8080`) and the Nginx-hosted React 19 SPA (`:3000`) in synchronized containers.
